# Huashu Design

Build high-fidelity, self-contained HTML prototypes, slides, and animations directly with HTML/CSS/JS — no build step required.

## Principles

- Output is a single self-contained `.html` file with inline CSS/JS.
- Prioritize visual polish: hierarchy, spacing, motion, and detail.
- Apply one design philosophy deliberately (e.g., material, brutalism, glassmorphism, editorial minimalism).

## Design Philosophies

Select from philosophies such as: minimalist, neo-brutalist, Swiss/International, glassmorphism, warm editorial, dark ambient, retro terminal, organic/soft, technical, luxury. State the chosen philosophy before building.

## Five-Dimension Review

After building, self-review across:
1. **Typography** — scale, rhythm, legibility.
2. **Color** — palette harmony and contrast.
3. **Layout** — alignment, whitespace, responsiveness.
4. **Motion** — purposeful transitions and micro-interactions.
5. **Polish** — edge cases, hover/focus states, details.

## Output

Deliver interactive HTML that works in any modern browser. For slides or animations, ensure they run in real time with no external dependencies.
