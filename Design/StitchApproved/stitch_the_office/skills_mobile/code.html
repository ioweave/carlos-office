Vendor Research

Vendor Research

Automates the process of finding, evaluating, and summarizing potential software vendors based on specific criteria.

Triggers

  • Incoming email requesting vendor options.
  • Manual execution via Carlos Suite with specific parameters.

Process Flow

The skill executes the following sequence:

  1. Parse request for required features, budget, and compliance needs.
  2. Query internal knowledge base for approved vendors.
  3. Perform web search for new alternatives if needed.
  4. Compile a comparison matrix.

Parameters

{
  "category": "string",
  "max_budget": "number",
  "required_certifications": ["SOC2", "ISO27001"]
}
