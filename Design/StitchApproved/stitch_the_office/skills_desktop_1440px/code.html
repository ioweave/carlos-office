Vendor Research

This skill instructs Nora on how to systematically evaluate new third-party software vendors to ensure they meet our internal compliance, security, and operational standards.

Core Objectives

  • Identify potential security risks associated with data handling and storage.
  • Verify compliance with SOC2, GDPR, and internal data residency requirements.
  • Assess integration capabilities with our current tech stack (primarily AWS, Snowflake, and Okta).
  • Summarize pricing tiers and enterprise SLA commitments.

Execution Steps

  1. Initial Intake: Receive vendor name and target use-case from user.
  2. Public Data Gathering: Scrape public documentation, security portals (e.g., trust.vendor.com), and terms of service.
  3. Compliance Check: Cross-reference gathered data against the internal compliance_matrix_v2.csv.
  4. Report Generation: Format findings into the standard Vendor Review Markdown template.
