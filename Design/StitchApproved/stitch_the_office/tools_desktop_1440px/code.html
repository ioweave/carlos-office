Web Search

cloud Provider: Tavily API memory Model: Optimized Search check_circle Approval: Not Required

Description

This tool securely interfaces with the Tavily search API to execute high-speed, targeted web queries. It is designed to return factual, cited summaries rather than raw HTML, making it optimal for autonomous agent ingestion. The tool automatically filters out ad-heavy or low-reputation domains to ensure data integrity.

Input Schema

JSON 
{
  "type": "object",
  "properties": {
    "query": {
      "type": "string",
      "description": "The exact search phrase to execute."
    },
    "max_results": {
      "type": "integer",
      "default": 5,
      "description": "Maximum number of sources to return."
    }
  },
  "required": ["query"]
}

Output Schema

JSON 
{
  "type": "object",
  "properties": {
    "results": {
      "type": "array",
      "items": {
        "type": "object",
        "properties": {
          "title": { "type": "string" },
          "url": { "type": "string" },
          "content": { "type": "string" }
        }
      }
    }
  }
}
